# EcoMatrix

Учебный экологический проект. Публикуемая версия взята из архива «Ало (3).zip».
Главный файл содержит CSS, JavaScript и фотографии; сборка и платный сервер не нужны.

Планируемый адрес: https://deputat-lab.github.io/ecomatrix/
Это адрес для выбранного аккаунта и имени репозитория, а не подтверждение публикации.

Прогресс хранится в браузере посетителя (localStorage), не в общей базе данных.
Дизайн, калькулятор, переключатель темы, задания и остальные функции архива сохранены.
Для запуска локально достаточно открыть index.html.
